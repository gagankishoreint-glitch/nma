# MISSION

We are testing whether a Titans-style neural memory module improves
multi-session task continuity in a 4GB-VRAM agent, compared to no
memory and context-window memory.

We are NOT:
- Building a production agent
- Claiming state-of-the-art
- Comparing to published Titans numbers
- Solving continual learning
- Solving procedural memory extraction in general

The only claim we will make:
"On a three-session synthetic task, a native memory module either does
or does not improve recall of Session 1 information in Session 3,
compared to two honest baselines."

If the answer is no, we report no. That is a valid result.
